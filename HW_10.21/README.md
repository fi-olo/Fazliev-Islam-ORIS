# Домашняя работа

## Изменения 

**Задание 1 — потеря соединения:**
- В `ReceiveThread` добавлен сигнал `connection_lost = pyqtSignal(str)`.
- В `run()` чтение из сокета обёрнуто в `try/except` (`ConnectionError`,
  `OSError`). Отдельно обработан `recv() == None`.
- GUI из потока не меняется — только сигнал.
- В `MainWindow` слот `on_connection_lost` пишет сообщение в историю,
  ставит `Disconnected`, блокирует ввод и кнопку Send.

**Задание 2 — остановка SendThread:**
- Добавлен метод `stop()`, который кладёт `None` в очередь.
- В `run()` при получении `None` — `break`.
- В `MainWindow.closeEvent`: `send_thread.stop()` + `wait(2000)`, затем
  `shutdown`/`close` сокета (будит `recv()`) + `receive_thread.wait(2000)`.
- Закрытие сокета перенесено из `main()` в `closeEvent`.

**Задание 3 — индикатор состояния:**
- `status_label` показывает `Connected` (зелёный) / `Disconnected` (красный)
  через метод `set_connected()`, вызываемый из слота по сигналу.

## Проверки

1. Запуск клиента — индикатор `Connected`, сообщения ходят.
2. Остановка сервера — `Disconnected`, сообщение в истории, ввод заблокирован,
   приложение не падает.
3. Закрытие окна при активном соединении — процесс завершается, потоков-зомби нет.
4. Закрытие окна после потери соединения — завершается корректно.
