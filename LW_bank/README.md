# F-Bank

Flask-приложение для учёта банковских счетов.

## Что реализовано

### Редактирование

- Маршрут `GET/POST /accounts/<id>/edit`.
- На странице счёта есть кнопка «Редактировать».
- Форма заполнена текущими данными счёта.
- Данные приходят через `request.form`.
- Сервер проверяет поля: имя и карта не пустые, баланс — число ≥ 0.
- Если есть ошибки — форма показывается снова с ошибками и введёнными значениями.
- Если всё верно — счёт обновляется и идёт `redirect` на его страницу.

### Дополнительные функции

1. **Поиск** — на главной по имени владельца и номеру карты (`?q=`).
2. **Сортировка** — по балансу (возр./убыв.) и по имени (`?sort=`).
3. **Статистика** — страница `/stats`: количество счетов, общий, средний,
   максимальный и минимальный баланс, топ-3.

Также есть перевод между счетами с проверками.

### Шаблоны (Часть 3)

- Все страницы наследуются от `base.html`.
- Ссылки сделаны через `url_for()`.
- Используются `for` и `if` в Jinja.
- Ошибки показываются в форме.
- При ошибках введённые значения не теряются.

## Маршруты

| Метод | URL | Что делает |
|-------|-----|------------|
| GET | `/` | Список счетов, поиск, сортировка |
| GET | `/accounts/<id>` | Подробности счёта |
| GET, POST | `/accounts/add` | Добавить счёт |
| GET, POST | `/accounts/<id>/edit` | Редактировать счёт |
| GET, POST | `/transfer` | Перевод между счетами |
| GET | `/stats` | Статистика |
