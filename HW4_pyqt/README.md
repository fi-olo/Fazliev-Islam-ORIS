# Task Manager на PyQt6

Desktop-приложение для создания задач

## Что умеет приложение

- Ввести название задачи
- Написать описание задачи
- Выбрать приоритет: Low, Medium или High
- Отметить дополнительные настройки: Important, Send notification, Add to favorites
- Нажать кнопку **Create task** и создать задачу
- Увидеть все созданные задачи в списке внутри окна
- Очистить форму кнопкой **Clear**
- Удалить последнюю задачу кнопкой **Delete last task**
- Отфильтровать задачи по приоритету через выпадающий список
- Следить за количеством задач через счётчик
- Видеть текущий статус приложения внизу окна

## Как установить


Установите PyQt6:

```bash
pip install PyQt6
```

## Как запустить

```bash
python main.py
```

## Как пользоваться

1. Введите название задачи в поле **Task**.
2. Напишите описание в поле **Description** (необязательно).
3. Выберите один из приоритетов: Low, Medium или High.
4. При необходимости отметьте дополнительные настройки.
5. Нажмите **Create task** — задача появится в списке.
6. Чтобы очистить форму, нажмите **Clear**.
7. Чтобы удалить последнюю задачу, нажмите **Delete last task**.
8. Чтобы отфильтровать задачи, выберите нужный приоритет в списке **Filter**.

## Какие виджеты используются

- **QMainWindow** — главное окно приложения
- **QWidget** — центральный виджет окна
- **QVBoxLayout** и **QHBoxLayout** — для размещения элементов
- **QLineEdit** — для ввода названия задачи
- **QTextEdit** — для ввода описания
- **QRadioButton** — для выбора приоритета
- **QCheckBox** — для дополнительных настроек
- **QPushButton** — для кнопок
- **QListWidget** — для отображения списка задач
- **QComboBox** — для фильтра по приоритету
- **QLabel** — для подписей и статуса
